accent-color
------------


> Browsers that support accent-color currently apply it to the following HTML elements:
> * input type="checkbox
> * input type="radio"
> * input type="range"
> * progress


Color scheme
------------

Browsers **automatically** choose a light/dark color scheme for those elements based on the applied accent-color.

For example, in checkboxes:
* light accent colours yield a tickmark that is black
* dark accent colours yield a tickmark that is white

For each shade there a crossover point where the browser flips from light to dark.

Firefox and chrome seem to differ slightly on exactly where the crossover point is for some colours.
